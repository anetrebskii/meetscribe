# Where to promote Chrome extension

## No reputation needed

- **Product Hunt** - anyone can submit
- **Reddit** - r/ChromeExtensions, r/SideProject, r/chrome (low/no karma requirements)
- **Dev.to / Hashnode** - publish immediately
- **X/Twitter, LinkedIn** - no restrictions
- **BetaList, AlternativeTo, SaaSHub, ToolHunt** - submit freely
- **Indie Hackers** - open posting
- **Hacker News (Show HN)** - minimal karma (1), get it by creating account
- **GitHub** - if open source

## Invite-only / reputation-gated

- **Lobste.rs** - invite-only
